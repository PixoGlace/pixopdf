功能恰到好处

一个始终流畅的 PDF 工作区。

所有工具都汇聚在同一套直观、非破坏式的工作流程中。

0

整理页面

移动、旋转、复制页面，或将页面标记为删除。原始页码保持不变，每项修改都会通过颜色清晰标示。

0

合并多个 PDF

添加多个文档，直观调整顺序，再导出为一个 PDF，原始文件不会被覆盖。

0

精准拆分

可按单页、固定页数批次或自定义范围拆分，并在导出前通过颜色预览每个结果。

0

插入空白页

在任意位置添加 A4 或 A5 空白页，并可选择纵向或横向。

0

非破坏式编辑历史

随时撤销或重做。删除的页面仍会以灰色显示，并可在导出前恢复。

0

多文档工作区

查看所有已打开的 PDF，移除误加的文件，或清空工作区，而不影响任何源文件。

从第一步开始就简单

三步获得想要的结果。

PDF
  1. 01

    添加 PDF

    将文件拖入窗口，或使用系统文件选择器打开。

  2. 02

    直观编辑

    选择操作和页面缩略图，并在应用前确认每一项更改。

  3. 03

    放心导出

    将结果保存为新文件。PixoPDF 绝不会在未提示的情况下覆盖源文档。

隐私融入设计

文件永远不会离开你的设备。

PixoPDF 直接在电脑上完成 PDF 操作。文档、文件名和内容均不会发送到远程服务。

更新请求不会包含 PDF、文件路径或任何文档元数据。

本地处理

导入、缩略图生成、编辑和导出都直接在你的设备上完成。

无需上传，无需账号

无需注册，也无需将文件交给云服务，即使离线也能正常工作。

有限且透明的联网

可选的更新检查仅会访问 GitHub 公共 Releases API。
